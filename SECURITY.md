# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in ShadowPaste, please report it
**privately**. Do not open a public GitHub issue.

- Use GitHub's **Private vulnerability reporting** (Security → Report a
  vulnerability) on this repository, or
- Email the maintainers at the address listed on the repository's profile.

Please include:

- A description of the issue and its impact
- Steps to reproduce (a proof-of-concept if possible)
- Affected version / commit

We aim to acknowledge reports within a few business days and will keep you
updated on remediation progress. We appreciate coordinated disclosure and will
credit reporters who wish to be named once a fix ships.

## Supported versions

The `main` branch receives security fixes. Pin to a tagged release for
stability and watch the repository for security advisories.
